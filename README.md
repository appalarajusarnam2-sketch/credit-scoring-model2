To predict an individual's creditworthiness using past financial data.

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn

## Machine Learning Models
- Logistic Regression
- Decision Tree
- Random Forest

## Evaluation Metrics
- Accuracy
- Precision
- Recall
- F1-Score
- ROC-AUC

## Features
- Income
- Debt
- Payment History
- Loan Amount
- Credit History
- Credit Utilization
